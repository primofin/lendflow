# Glossary / Bảng thuật ngữ (EN / VI)

| English | Tiếng Việt | Meaning |
|---|---|---|
| Borrower | Người vay / Khách hàng vay | Person applying for a loan |
| Loan officer / Relationship manager (RM) | Nhân viên tín dụng / Cán bộ quan hệ khách hàng | Staff who receives and processes applications |
| Supervisor | Trưởng nhóm / Cấp phê duyệt | Approves exceptions and large loans |
| Credit institution | Tổ chức tín dụng (TCTD) | Bank or finance company licensed to lend |
| State Bank of Vietnam (SBV) | Ngân hàng Nhà nước (NHNN) | Banking regulator |
| Credit information centre (CIC) | Trung tâm Thông tin tín dụng Quốc gia (CIC) | National credit bureau |
| National citizen ID (CCCD) | Căn cước công dân (CCCD) | 12-digit ID card |
| Know your customer (KYC) | Định danh / xác minh khách hàng | Verifying who the customer is |
| Electronic KYC (eKYC) | Xác thực khách hàng điện tử | KYC done online (e.g. ID image + selfie) |
| Anti-money laundering (AML) | Phòng chống rửa tiền | Duties to detect and report suspicious activity |
| Debt group | Nhóm nợ | Classification of a loan by repayment status (groups 1 to 5) |
| Non-performing loan (NPL) / bad debt | Nợ xấu | Debt in groups 3 to 5 |
| NPL ratio | Tỷ lệ nợ xấu | Bad debt as a share of total debt |
| Debt-to-income (DTI) | Tỷ lệ nợ trên thu nhập | Monthly debt payments divided by monthly income |
| Loan-to-value (LTV) | Tỷ lệ cho vay trên giá trị tài sản | Loan divided by collateral value |
| Principal | Tiền gốc | Amount borrowed |
| Interest | Tiền lãi | Cost of borrowing |
| Term / tenor | Kỳ hạn vay | Length of the loan |
| Instalment | Số tiền trả mỗi kỳ | Regular payment |
| Reducing-balance interest | Lãi suất tính trên dư nợ giảm dần | Interest charged on the remaining balance |
| Flat-rate interest | Lãi suất tính trên dư nợ gốc ban đầu | Interest charged on the original amount throughout |
| Annuity (equal instalment) | Trả góp đều (niên kim) | Same total payment each period |
| Collateral | Tài sản bảo đảm | Asset pledged to secure a loan |
| Unsecured loan | Vay tín chấp | Loan without collateral |
| Credit scoring | Chấm điểm tín dụng | Estimating repayment likelihood |
| Origination | Khởi tạo khoản vay | Process from application to disbursement |
| Disbursement | Giải ngân | Release of funds |
| Servicing | Quản lý khoản vay | Handling a loan after disbursement |
| Collections | Thu hồi nợ | Recovering overdue payments |
| Write-off | Xóa nợ / xử lý rủi ro | Removing an unrecoverable debt from the books |
| Personal data | Dữ liệu cá nhân | Information relating to an individual |
| Consent | Sự đồng ý | Permission to process personal data |
| Data subject | Chủ thể dữ liệu | The person the data is about |
| Data protection officer (DPO) | Cán bộ bảo vệ dữ liệu cá nhân | Responsible for compliance with data rules |
| Electronic signature | Chữ ký điện tử | Signature in electronic form |
| Digital signature | Chữ ký số | Cryptographic e-signature with a certificate |
| Audit trail | Dấu vết kiểm toán | Record of who did what and when |
| Service-level agreement (SLA) | Cam kết mức độ dịch vụ | Target response or processing time |
| User story | Câu chuyện người dùng | Short requirement from the user's view |
| Acceptance criteria (AC) | Tiêu chí chấp nhận | Testable conditions for "done" |
| MoSCoW | Phân loại ưu tiên MoSCoW | Must / Should / Could / Won't |
| BPMN | Mô hình hóa quy trình BPMN | Standard notation for business processes |
| As-Is / To-Be | Hiện trạng / Tương lai | Current process / improved process |
| Pain point | Điểm đau | A user's problem or frustration |
| UAT | Kiểm thử chấp nhận người dùng | Final testing by business users |
| Traceability | Truy vết yêu cầu | Linking requirement, design, code and test |
